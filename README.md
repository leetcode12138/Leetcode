# Leetcode

Leetcode 算法和数据结构题目分类和解析。

## 题解目录

从 [Leetcode 题解 - 目录](notes/Leetcode%20题解%20-%20目录.md) 开始阅读。

保留 CS-Notes 的 16 个分类、题目顺序、输入输出示例、解题思路和复杂度分析，移除原作者的解答代码与图片。可以在阅读后自行实现题目。

## 在本地 VS Code 中打开

在电脑终端执行：

```sh
git clone https://github.com/leetcode12138/Leetcode.git
cd Leetcode
code .
```

也可以在 VS Code 中打开命令面板，选择 `Git: Clone`，输入上面的仓库地址，选择本地保存目录并打开。

打开 `notes/Leetcode 题解 - 目录.md`，使用“打开侧边预览”（Windows/Linux：Ctrl+K V；macOS：Cmd+K V）浏览分类和题解。

本仓库是 Markdown 笔记，无需安装项目依赖或启动服务。
